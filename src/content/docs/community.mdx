# 社区

## 提问与交流

想参与 Radix 社区、提问、分享技巧，可以加入 [Discord](https://discord.com/invite/7Xb99uG)。

## 关注更新

想接收新原语的发布、公告、博客文章以及各类 Radix 使用技巧，可以关注 [Bluesky](https://bsky.app/profile/radix-ui.com) 或 [Twitter](https://twitter.com/radix_ui)。

## 反馈与贡献

提交问题、请求功能、参与贡献，请到 [GitHub](https://github.com/radix-ui/primitives)。贡献前请遵循[贡献指南](https://github.com/radix-ui/primitives/blob/main/.github/CONTRIBUTING.md)。
