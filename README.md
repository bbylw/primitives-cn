# Radix Primitives

**一个用于构建高质量、无障碍设计系统与 Web 应用的开源 UI 组件库。**

Radix Primitives 是一套底层 UI 组件库，重点关注无障碍性、可定制性与开发者体验。你可以将这些组件作为设计系统的基础层，也可以按需逐步采用。

---

## 安装

首先，如果尚未安装 pnpm，请先在终端中运行：

```bash
npm install -g pnpm
```

然后安装依赖：

```bash
pnpm install
```
